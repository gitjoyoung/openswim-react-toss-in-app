## 절대 규칙

1. **`INSERT` 만 허용한다. 기존 행의 어떤 컬럼도 수정하지 않는다.**
   조사 중 "이미 DB에 있는 시설이었다" 또는 "기존 행이 틀렸다"를 발견하면 직접 고치지 말고
   `docs/data/worksplit/handoff-B-to-A.jsonl` 에 append 하고 넘어간다.
2. **등록 전 중복 확인이 1순위다.** 이름 정규화만으로는 부족하다는 게 이미 확인됐다
   (예: "부산국민체육센터 실내수영장" ↔ DB "부산국민체육센터", "용인시청소년수련원" ↔ DB
   "용인청소년수련관"). 이름 정규화 + 좌표 150m 이내 + 전화번호 일치 + 주소 도로명 대조를
   모두 돌리고, 애매하면 등록하지 말고 보류 목록에 남긴다.
3. **추측 금지.** 자유수영 시간표는 공식 출처로 확인된 것만 넣는다. 못 찾으면 `free_swim` 을
   비운 채 등록하고 `free_swim_confidence = 'needs_check'`, `free_swim_note` 에 사유를 남긴다.
4. **사진은 넣지 않는다.** 권리관계가 확인되지 않은 이미지는 기본값이 "게시하지 않음"이다.
   `.go.kr` 지자체 출처이고 식별 가능한 인물이 없는 경우에만 후보로 올리고, 승인 없이 R2에
   올리지 않는다.
5. Neon 프로덕션에 실제로 INSERT 하기 전에 등록 대상 목록(시설명·주소·자유수영 유무·출처)을
   보고하고 승인을 받는다.
6. 브라우저 탭은 동시 1개만 쓰고 재사용한다. 병렬 브라우저 서브에이전트 금지.

## 커버리지 확대 (P1)

현재 대조는 helloswim / swimmingis / oneul-swim 세 디렉터리 기준이라 전수가 아니다.
아래 중 접근 가능한 것으로 전수 대조를 한 번 더 돌린다:
- 행안부 LOCALDATA 체육시설업(수영장업) 인허가 데이터
- 문체부 전국공공체육시설 표준데이터 (data.go.kr)

둘 다 API 키가 필요하다. 키가 없으면 **키 발급이 필요하다고 사용자에게 알리고 멈춘다.**
키 없이 우회하겠다고 지도 크롤링 같은 걸로 새지 말 것.

또한 대조에 쓴 aggregator 캐시(`tmp/pool-research/*.json`)는 2026-08-21자다.
현재 helloswim 사이트맵은 997건이라 4건 차이가 있으니 `--refresh` 로 재수집 후 재대조한다.
